# 质量筛选与领域迁移

## 两轮筛选

**第一轮：来源与相关性。** 核实标题、作者、正式发表状态和版本，检查是否真正回答研究问题。顶刊、顶会、引用量和新近程度仅作为线索；不能替代内容评审。

**第二轮：正文与证据。** 阅读研究设计、方法、主要结果、附录与局限，判断证据是否支持作者主张。缺少关键正文时停留在“待评审”，不打高质量标签。

输出建议为 `优先精读 / 补充阅读 / 暂缓 / 排除 / 信息不足`，每项写理由与证据定位。不使用没有解释依据的总分，也不承诺论文结论一定正确。

## 通用检查表

- 问题：研究对象、范围和结论适用条件是否明确？
- 贡献：相对已有研究增加了什么？是否只是换场景或指标？
- 证据：数据来源、样本、比较对象、方法假设是否可核查？
- 论证：统计相关、预测能力和因果效应是否被混淆？
- 稳健性：是否检查替代解释、敏感性、异质性与失败情形？
- 透明度：代码、数据或详细方法是否可获得？受保密约束的研究需明确复核限制，不直接判为低质量。
- 版本：更正、撤稿、正式发表稿与工作稿是否影响当前解读？
- 学习价值：是否适合当前基础，能否帮助解决具体问题？

## 什么可以复用，什么要替换

| 层次 | 可复用部分 | 换领域时需要调整 |
|---|---|---|
| 检索 | 问题、关键词、来源与日志 | 专业数据库、术语、重要文献类型 |
| 归档 | DOI/标识符、版本、分类、状态 | 学科特定字段与方法标签 |
| 评审 | 主张—证据—局限 | 本领域对证据强弱的判断 |
| 教学 | 背景、方法、例子、练习 | 所需数学、制度与专业知识 |
| 综合 | 比较不同结论与适用边界 | 领域中的争议与证据积累方式 |

经济学与财政学的评审尤其关注：识别策略、内生性、选择偏差、测量误差、政策实施背景、估计对象、标准误与推断、外部有效性。使用工具变量时检查相关性和排除限制；使用双重差分时检查设计及其适用假设。这些是学习检查点，不是几项机械测试就能保证因果识别成立。

理论论文应关注假设、推导、均衡条件和比较静态；描述性研究则关注测量、覆盖范围与口径，不应强行要求所有研究都采用因果设计。

## 如何讲解一篇论文

先说论文试图回答什么，再补必要背景；随后解释方法为什么可能回答该问题，逐项核对证据，最后讨论结论边界。用简单例子帮助理解，但把例子标为教学解释。

精读后至少能回答三个问题：作者发现了什么？凭什么这样判断？什么情况下结论可能不成立？
